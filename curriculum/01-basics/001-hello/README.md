# 001 · 返回第一条消息

## 学习目标

理解代码执行结果与 return。

## 前置知识

无需编程基础。

## 先学一点

Python 用引号包住文字。`def hello():` 是准备好的函数外壳；其下缩进四个空格的代码是你要填写的部分。`return "你好"` 会把文字交给调用者；`print` 只是显示文字，不能代替返回值。先保留外壳即可，函数设计会在后面学习。

## 任务与约定

完成 `hello()`，准确返回字符串 `Hello, Python!`，注意空格、大小写和感叹号。

除题目明确要求外，不修改传入的可变数据，不额外打印内容。只验收约定范围内的输入，不要求猜测未说明的规则。

`hello()` → `"Hello, Python!"`
