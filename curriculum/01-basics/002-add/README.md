# 002 · 计算两项费用

## 学习目标

使用加法计算整数结果。

## 前置知识

先完成第 001 题及其前置练习；本题复用此前学过的知识。

## 先学一点

`def total(a, b):` 中 a 和 b 是调用时提供的数值，可直接用于表达式。`+` 是加法，`return a` 会返回 a 的值。

## 任务与约定

完成 `total(a, b)`，输入两个整数（可为负数和零），返回它们的和。费用单位为分，负数表示退款。

除题目明确要求外，不修改传入的可变数据，不额外打印内容。只验收约定范围内的输入，不要求猜测未说明的规则。

## 示例

`total(120, 30)` → `150`
