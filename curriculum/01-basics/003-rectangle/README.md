# 003 · 计算矩形面积

## 学习目标

使用乘法。

## 前置知识

先完成第 002 题及其前置练习；本题复用此前学过的知识。

## 先学一点

`*` 表示乘法，如 `3 * 4` 的结果是 12。

## 任务与约定

完成 `area(width, height)`。两边是非负整数，返回面积；任一边为零时面积为零。

除题目明确要求外，不修改传入的可变数据，不额外打印内容。只验收约定范围内的输入，不要求猜测未说明的规则。

## 示例

`area(3, 7)` → `21`
