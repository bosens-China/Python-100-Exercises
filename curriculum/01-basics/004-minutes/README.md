# 004 · 换算完整分钟

## 学习目标

区分整数除法与普通除法。

## 前置知识

先完成第 003 题及其前置练习；本题复用此前学过的知识。

## 先学一点

`//` 返回向下取整的商；`/` 返回普通除法结果。例如 `7 // 3` 是 2。

## 任务与约定

完成 `whole_minutes(seconds)`，输入非负整数秒数，返回其中完整的分钟数（整数），不足一分钟的部分舍去。

除题目明确要求外，不修改传入的可变数据，不额外打印内容。只验收约定范围内的输入，不要求猜测未说明的规则。

## 示例

`whole_minutes(125)` → `2`
