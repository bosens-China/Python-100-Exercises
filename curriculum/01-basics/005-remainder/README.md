# 005 · 计算剩余秒数

## 学习目标

使用取余运算。

## 前置知识

先完成第 004 题及其前置练习；本题复用此前学过的知识。

## 先学一点

`%` 计算余数，例如 `7 % 3` 是 1。

## 任务与约定

完成 `remaining_seconds(seconds)`，输入非负整数秒数，返回扣除完整分钟后的剩余秒数，范围为 0–59。

除题目明确要求外，不修改传入的可变数据，不额外打印内容。只验收约定范围内的输入，不要求猜测未说明的规则。

## 示例

`remaining_seconds(125)` → `5`
