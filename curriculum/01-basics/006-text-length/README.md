# 006 · 测量文字长度

## 学习目标

调用已有的内置函数。

## 前置知识

## 先学一点

`len(text)` 返回字符串长度，空格也算一个字符。本题按 Python 字符串的字符数计数。

## 任务与约定

完成 `text_length(text)`，输入任意字符串，返回字符数；空字符串返回 0。

除题目明确要求外，不修改传入的可变数据，不额外打印内容。只验收约定范围内的输入，不要求猜测未说明的规则。

## 示例

`text_length("你好 Python")` → `9`
