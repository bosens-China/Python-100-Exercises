# 007 · 拼接欢迎语

## 学习目标

拼接字符串。

## 前置知识

先完成第 006 题及其前置练习；本题复用此前学过的知识。

## 先学一点

两个字符串用 `+` 可以连接；引号内的空格会原样保留。

## 任务与约定

完成 `greet(name)`，输入字符串，返回 `你好，` 加上原始 name 再加 `！`。不去空格；空名字也按此规则。

除题目明确要求外，不修改传入的可变数据，不额外打印内容。只验收约定范围内的输入，不要求猜测未说明的规则。

## 示例

`greet("小林")` → `"你好，小林！"`
