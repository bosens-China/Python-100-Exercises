# 009 · 把数量文字转成数字

## 学习目标

进行基本类型转换。

## 前置知识

先完成第 008 题及其前置练习；本题复用此前学过的知识。

## 先学一点

`int("12")` 把整数文字变成数字，之后才能做数值加法。

## 任务与约定

完成 `next_count(text)`。输入始终是合法的十进制整数字符串，可有首尾空格或负号。返回转换后的整数加 1；本题不处理非法文字。

除题目明确要求外，不修改传入的可变数据，不额外打印内容。只验收约定范围内的输入，不要求猜测未说明的规则。

## 示例

`next_count(" 9 ")` → `10`
