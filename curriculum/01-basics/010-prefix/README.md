# 010 · 截取摘要

## 学习目标

使用字符串切片。

## 前置知识

先完成第 009 题及其前置练习；本题复用此前学过的知识。

## 先学一点

`text[:n]` 取得前 n 个字符；n 超过长度时得到整个字符串，不会报错。

## 任务与约定

完成 `preview(text, limit)`。text 是字符串，limit 是非负整数，返回最多 limit 个字符；不附加省略号。

除题目明确要求外，不修改传入的可变数据，不额外打印内容。只验收约定范围内的输入，不要求猜测未说明的规则。

## 示例

`preview("Python", 3)` → `"Pyt"`

## 开始编写

编辑 `main.py`。起始代码位于 [starter](./starter/)，测试位于 [test/test_solution.py](./test/test_solution.py)。起始代码尚未完成，出现未通过是正常反馈。
