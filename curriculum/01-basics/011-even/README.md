# 011 · 判断是否为偶数

## 学习目标

返回布尔值。

## 前置知识

先完成第 010 题及其前置练习；本题复用此前学过的知识。

## 先学一点

`==` 比较两个值是否相等，得到 True 或 False；`=` 是赋值。偶数除以 2 的余数为零。

## 任务与约定

完成 `is_even(number)`，输入整数，返回 bool：偶数为 True，奇数为 False；零与负偶数也是偶数。
