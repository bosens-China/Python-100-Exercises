# 012 · 生成购物小票

## 学习目标

组合转换、计算与格式化。

## 前置知识

先完成第 011 题及其前置练习；本题复用此前学过的知识。

## 先学一点

`f"数量：{count}"` 会把变量放入字符串；花括号内也可写表达式。

## 任务与约定

完成 `receipt(name, unit_price, quantity)`，name 是字符串，价格与数量为非负整数。返回 `名称 × 数量 = 总价分`，乘号两侧和等号两侧各一个空格。

除题目明确要求外，不修改传入的可变数据，不额外打印内容。只验收约定范围内的输入，不要求猜测未说明的规则。

## 示例

`receipt("笔", 150, 2)` → `"笔 × 2 = 300分"`
