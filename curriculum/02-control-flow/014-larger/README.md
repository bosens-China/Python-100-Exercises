# 014 · 选择较大值

## 学习目标

处理相等的分支边界。

## 前置知识

先完成第 013 题及其前置练习；本题复用此前学过的知识。

## 先学一点

`>=` 表示大于或等于。函数执行 return 后就会结束。

## 任务与约定

完成 `larger(a, b)`，输入两个整数，返回较大的值；相等时返回这个共同的值。

除题目明确要求外，不修改传入的可变数据，不额外打印内容。只验收约定范围内的输入，不要求猜测未说明的规则。

## 示例

`larger(4, 9)` → `9`
