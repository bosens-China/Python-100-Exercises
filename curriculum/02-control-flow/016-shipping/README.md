# 016 · 计算包邮条件

## 学习目标

组合布尔条件。

## 前置知识

先完成第 015 题及其前置练习；本题复用此前学过的知识。

## 先学一点

`and` 要求两个条件都成立，`or` 只要求至少一个成立。布尔参数可以直接用在 if 条件中。

## 任务与约定

完成 `shipping_fee(amount, is_member)`。amount 是非负整数分，is_member 是 bool。会员或订单金额至少 9900 分时包邮（0），否则运费 800 分。

除题目明确要求外，不修改传入的可变数据，不额外打印内容。只验收约定范围内的输入，不要求猜测未说明的规则。

## 示例

`shipping_fee(100, True)` → `0`
