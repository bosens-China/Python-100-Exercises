# 017 · 判断闰年

## 学习目标

把有例外的规则转换为条件。

## 前置知识

先完成第 016 题及其前置练习；本题复用此前学过的知识。

## 先学一点

括号可以清楚表达组合条件。能被某数整除可以用取余为零来判断。

## 任务与约定

完成 `is_leap(year)`，year 是正整数。能被 400 整除，或能被 4 整除但不能被 100 整除时返回 True，否则 False。

除题目明确要求外，不修改传入的可变数据，不额外打印内容。只验收约定范围内的输入，不要求猜测未说明的规则。

## 示例

`is_leap(2000)` → `True`；`is_leap(1900)` → `False`
