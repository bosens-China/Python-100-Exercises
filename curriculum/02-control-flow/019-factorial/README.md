# 019 · 累计乘积

## 学习目标

选择正确的循环初始值。

## 前置知识

先完成第 018 题及其前置练习；本题复用此前学过的知识。

## 先学一点

`result *= number` 是 `result = result * number` 的简写。乘积的初始值通常是 1。

## 任务与约定

完成 `factorial(n)`，n 是 0–12 的整数，返回 1 到 n 的乘积，约定 0 的阶乘为 1。

除题目明确要求外，不修改传入的可变数据，不额外打印内容。只验收约定范围内的输入，不要求猜测未说明的规则。

## 示例

`factorial(4)` → `24`
