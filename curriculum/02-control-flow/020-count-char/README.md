# 020 · 统计指定字符

## 学习目标

遍历字符串并在条件满足时累加。

## 前置知识

先完成第 019 题及其前置练习；本题复用此前学过的知识。

## 先学一点

`for char in text:` 按顺序取得每个字符，不需要手动维护位置。

## 任务与约定

完成 `count_char(text, target)`，text 是字符串，target 保证只有一个字符。大小写敏感，返回出现次数。

除题目明确要求外，不修改传入的可变数据，不额外打印内容。只验收约定范围内的输入，不要求猜测未说明的规则。

## 示例

`count_char("banana", "a")` → `3`
