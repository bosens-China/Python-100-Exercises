# 021 · 找到第一个数字字符

## 学习目标

用提前返回结束查找。

## 前置知识

先完成第 020 题及其前置练习；本题复用此前学过的知识。

## 先学一点

`"0" <= char <= "9"` 判断 ASCII 数字字符。循环内 return 会结束整个函数；循环后可以返回未找到的结果。

## 任务与约定

完成 `first_digit(text)`，返回字符串中第一个 ASCII 数字字符；没有则返回空字符串。不要把数字字符转换为整数。

除题目明确要求外，不修改传入的可变数据，不额外打印内容。只验收约定范围内的输入，不要求猜测未说明的规则。

## 示例

`first_digit("room 42")` → `"4"`
