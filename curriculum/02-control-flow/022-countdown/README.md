# 022 · 倒计时文本

## 学习目标

使用 while 并保证循环前进。

## 前置知识

先完成第 021 题及其前置练习；本题复用此前学过的知识。

## 先学一点

`while n > 0:` 会重复执行，直到条件不成立。每轮需要改变 n，否则可能永不结束。

## 任务与约定

完成 `countdown(n)`，n 是 0–20 的整数，返回从 n 到 1 的数字文本，每个数字后接一个空格，最后接 `开始`。n 为零只返回 `开始`。

除题目明确要求外，不修改传入的可变数据，不额外打印内容。只验收约定范围内的输入，不要求猜测未说明的规则。

## 示例

`countdown(3)` → `"3 2 1 开始"`
