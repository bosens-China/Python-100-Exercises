# 024 · 检查密码练习规则

## 学习目标

综合循环、标记变量和条件。

## 前置知识

先完成第 023 题及其前置练习；本题复用此前学过的知识。

## 先学一点

可以用两个初始为 False 的变量记录是否见过字母和数字，遍历结束后汇总。此题是条件练习，不是生产密码安全方案。

## 任务与约定

完成 `valid_password(text)`，只有长度至少 8 且包含至少一个 ASCII 英文字母和一个 ASCII 数字时返回 True，其他返回 False。其他字符允许存在但不算英文字母或数字。

除题目明确要求外，不修改传入的可变数据，不额外打印内容。只验收约定范围内的输入，不要求猜测未说明的规则。

## 示例

`valid_password("python12")` → `True`
