## 先学一点

列表用方括号容纳多个值，如 `[4, 8]`；下标从 0 开始。`None` 表示没有值。空列表不能直接读取下标 0。

## 任务与约定

完成 `first_item(items)`，输入整数列表，非空返回首项，空列表返回 None。

除题目明确要求外，不修改传入的可变数据，不额外打印内容。只验收约定范围内的输入，不要求猜测未说明的规则。

## 示例

`first_item([4, 8])` → `4`
