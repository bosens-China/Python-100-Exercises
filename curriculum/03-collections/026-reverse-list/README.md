# 026 · 倒序复制列表

## 学习目标

返回新列表，避免意外修改输入。

## 前置知识

先完成第 025 题及其前置练习；本题复用此前学过的知识。

## 先学一点

`items[::-1]` 使用步长 -1 生成倒序副本。`items.reverse()` 则原地修改列表；两者的行为不同。

## 任务与约定

完成 `reversed_copy(items)`，输入整数列表，返回倒序的新列表。结果必须是独立对象，原列表保持不变。

除题目明确要求外，不修改传入的可变数据，不额外打印内容。只验收约定范围内的输入，不要求猜测未说明的规则。

## 示例

`reversed_copy([1, 2, 3])` → `[3, 2, 1]`
