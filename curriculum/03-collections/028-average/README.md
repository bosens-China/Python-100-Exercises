# 028 · 计算列表平均值

## 学习目标

处理空集合与除法。

## 前置知识

先完成第 027 题及其前置练习；本题复用此前学过的知识。

## 先学一点

`sum(numbers)` 可以计算列表总和。平均值是总和除以数量；空列表必须先单独处理。

## 任务与约定

完成 `average(numbers)`，输入整数列表；非空返回算术平均值，空列表返回 None。

除题目明确要求外，不修改传入的可变数据，不额外打印内容。只验收约定范围内的输入，不要求猜测未说明的规则。
