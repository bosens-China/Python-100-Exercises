# 029 · 按首次出现顺序去重

## 学习目标

用成员判断实现有序去重。

## 前置知识

先完成第 028 题及其前置练习；本题复用此前学过的知识。

## 先学一点

`value in items` 检查是否包含某值，`not in` 检查是否尚未包含。集合可以去重，但直接转换可能丢失所需顺序。

## 任务与约定

完成 `unique(items)`，输入字符串列表，返回去重后的列表，按首次出现顺序排列，大小写敏感。

除题目明确要求外，不修改传入的可变数据，不额外打印内容。只验收约定范围内的输入，不要求猜测未说明的规则。

## 示例

`unique(["b", "a", "b"])` → `["b", "a"]`
