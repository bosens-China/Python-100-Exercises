# 031 · 统计词频

## 学习目标

用字典累计计数。

## 前置知识

先完成第 030 题及其前置练习；本题复用此前学过的知识。

## 先学一点

`counts[word] = value` 设置键值；`.get(word, 0)` 可给未见过的词一个初始次数。

## 任务与约定

完成 `word_counts(words)`，输入字符串列表，返回每个字符串的出现次数；大小写敏感，空输入返回空字典。

除题目明确要求外，不修改传入的可变数据，不额外打印内容。只验收约定范围内的输入，不要求猜测未说明的规则。

## 示例

`word_counts(["py", "js", "py"])` → `{"py": 2, "js": 1}`

编辑 `main.py`。起始代码位于 [starter](./starter/)，测试位于 [test/test_solution.py](./test/test_solution.py)。起始代码尚未完成，出现未通过是正常反馈。
