# 032 · 合并库存数量

## 学习目标

遍历字典键值对并复制数据。

## 前置知识

先完成第 031 题及其前置练习；本题复用此前学过的知识。

## 先学一点

`mapping.items()` 提供键和值；`mapping.copy()` 创建浅副本。本题值都是整数，浅副本已足够。

## 任务与约定

完成 `merge_stock(left, right)`，两个字典将商品名映射到非负整数数量。返回合并字典，相同商品数量相加，输入均不变。

除题目明确要求外，不修改传入的可变数据，不额外打印内容。只验收约定范围内的输入，不要求猜测未说明的规则。

## 示例

`merge_stock({"笔": 2}, {"笔": 3, "本": 1})` → `{"笔": 5, "本": 1}`
