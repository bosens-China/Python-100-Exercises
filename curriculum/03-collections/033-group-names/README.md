# 033 · 按首字母分组

## 学习目标

把列表作为字典的值。

## 前置知识

先完成第 032 题及其前置练习；本题复用此前学过的知识。

## 先学一点

字典的值也可以是列表；可先为新分组创建空列表，再加入成员。`name[0]` 取第一个字符。

## 任务与约定

完成 `group_names(names)`，输入非空字符串组成的列表（列表本身可空）。按首字符分组，区分大小写，组内保留原顺序和重复项。

除题目明确要求外，不修改传入的可变数据，不额外打印内容。只验收约定范围内的输入，不要求猜测未说明的规则。

## 示例

`group_names(["Amy", "Ann", "Bob"])` → `{"A": ["Amy", "Ann"], "B": ["Bob"]}`
