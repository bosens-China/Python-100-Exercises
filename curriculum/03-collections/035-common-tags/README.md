# 035 · 找共同标签

## 学习目标

认识集合与交集。

## 前置知识

先完成第 034 题及其前置练习；本题复用此前学过的知识。

## 先学一点

`set(items)` 创建去重集合；两个集合用 `&` 求交集。集合没有课程要求的展示顺序，可以最后 sorted。

## 任务与约定

完成 `common_tags(left, right)`，输入两个字符串列表，返回共同标签的去重列表，按 Python 字符串升序排列，区分大小写。

除题目明确要求外，不修改传入的可变数据，不额外打印内容。只验收约定范围内的输入，不要求猜测未说明的规则。

## 示例

`common_tags(["py", "web", "py"], ["py", "db"])` → `["py"]`
