# 036 · 展开一层列表

## 学习目标

使用嵌套循环。

## 前置知识

先完成第 035 题及其前置练习；本题复用此前学过的知识。

## 先学一点

外层循环遍历每个子列表，内层循环遍历子列表成员。只展开一层，不需要递归。

## 任务与约定

完成 `flatten(rows)`，rows 是整数列表组成的列表，返回按行顺序展开的一维列表。允许空行与空输入。

除题目明确要求外，不修改传入的可变数据，不额外打印内容。只验收约定范围内的输入，不要求猜测未说明的规则。

## 示例

`flatten([[1, 2], [], [3]])` → `[1, 2, 3]`
