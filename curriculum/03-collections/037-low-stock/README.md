# 037 · 筛选缺货商品

## 学习目标

组合字典遍历、条件与排序。

## 前置知识

先完成第 036 题及其前置练习；本题复用此前学过的知识。

## 先学一点

结果只有商品名，可以收集后排序，使展示顺序稳定。

## 任务与约定

完成 `low_stock(stock, threshold)`，stock 为商品名到非负整数库存的字典，threshold 为非负整数。返回库存严格小于阈值的商品名，升序排列。

除题目明确要求外，不修改传入的可变数据，不额外打印内容。只验收约定范围内的输入，不要求猜测未说明的规则。

## 示例

`low_stock({"b": 2, "a": 0}, 2)` → `["a"]`
