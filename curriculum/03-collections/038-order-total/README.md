# 038 · 汇总订单金额

## 学习目标

处理字典列表中的业务字段。

## 前置知识

先完成第 037 题及其前置练习；本题复用此前学过的知识。

## 先学一点

可以先取列表中的一条字典记录，再用键读取字段，例如 `row["quantity"]`。金额以整数分计算。

## 任务与约定

完成 `order_total(items)`。每条记录均有非负整数 `price`（单价分）和 `quantity`；返回总金额，空订单为 0。忽略其他字段，不改变输入。

除题目明确要求外，不修改传入的可变数据，不额外打印内容。只验收约定范围内的输入，不要求猜测未说明的规则。

## 示例

`order_total([{"price": 150, "quantity": 2}])` → `300`

## 开始编写

编辑 `main.py`。起始代码位于 [starter](./starter/)，测试位于 [test/test_solution.py](./test/test_solution.py)。起始代码尚未完成，出现未通过是正常反馈。
