# 039 · 提供默认问候对象

## 学习目标

定义默认参数。

## 前置知识

先完成第 038 题及其前置练习；本题复用此前学过的知识。

## 先学一点

`def greet(name="朋友"):` 允许调用者省略 name。只有省略参数才使用默认值，传入空字符串不会触发默认值。

## 任务与约定

完成 `greet(name="朋友")`，返回 `你好，` 加 name；无感叹号。支持省略、位置或关键字传参。

除题目明确要求外，不修改传入的可变数据，不额外打印内容。只验收约定范围内的输入，不要求猜测未说明的规则。

## 示例

`greet()` → `"你好，朋友"`
