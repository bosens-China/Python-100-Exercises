# 042 · 接收多项费用

## 学习目标

认识可变位置参数。

## 前置知识

先完成第 041 题及其前置练习；本题复用此前学过的知识。

## 先学一点

`def total(*amounts):` 会把任意数量的位置参数收集起来，可遍历或交给 sum。星号是函数签名的一部分。

## 任务与约定

完成 `total(*amounts)`，接收零个或多个整数并返回和；允许负数，无参数返回 0。

除题目明确要求外，不修改传入的可变数据，不额外打印内容。只验收约定范围内的输入，不要求猜测未说明的规则。

## 示例

`total(10, -2, 5)` → `13`
