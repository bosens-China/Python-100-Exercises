# 043 · 同时返回商和余数

## 学习目标

使用元组返回多个结果。

## 前置知识

先完成第 042 题及其前置练习；本题复用此前学过的知识。

## 先学一点

`return first, second` 返回一个元组，例如 `(2, 1)`。调用者可以通过 `q, r = divide(7, 3)` 同时取出两项。

## 任务与约定

完成 `divide(a, b)`，a 是非负整数，b 是正整数。返回 `(整数商, 余数)` 元组。

除题目明确要求外，不修改传入的可变数据，不额外打印内容。只验收约定范围内的输入，不要求猜测未说明的规则。

## 示例

`divide(7, 3)` → `(2, 1)`
