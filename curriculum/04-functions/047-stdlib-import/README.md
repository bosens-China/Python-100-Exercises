# 047 · 使用标准库求整数平方根

## 学习目标

使用 import 复用模块能力。

## 前置知识

先完成第 046 题及其前置练习；本题复用此前学过的知识。

## 先学一点

`import math` 导入标准库。`math.isqrt(n)` 返回非负整数 n 的整数平方根，即平方不超过 n 的最大整数。

## 任务与约定

完成 `square_side(area)`，area 是非负整数，返回能够容纳在该面积内的最大整数正方形边长；不使用浮点近似。

除题目明确要求外，不修改传入的可变数据，不额外打印内容。只验收约定范围内的输入，不要求猜测未说明的规则。

## 示例

`square_side(15)` → `3`
