# 049 · 复用筛选规则

## 学习目标

把筛选条件作为函数参数。

## 前置知识

先完成第 048 题及其前置练习；本题复用此前学过的知识。

## 先学一点

一个返回 True 或 False 的函数可以作为筛选规则。只保留规则返回真值的元素。

## 任务与约定

完成 `select(items, predicate)`，输入整数列表与单参数判断函数，返回满足条件的原始元素，保留顺序和重复项；不要把判断结果放进列表。

除题目明确要求外，不修改传入的可变数据，不额外打印内容。只验收约定范围内的输入，不要求猜测未说明的规则。

## 示例

`select([1, 2, 3], lambda n: n > 1)` → `[2, 3]`
