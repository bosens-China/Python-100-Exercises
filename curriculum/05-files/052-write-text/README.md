# 052 · 保存文本结果

## 学习目标

写入并覆盖文件。

## 前置知识

先完成第 051 题及其前置练习；本题复用此前学过的知识。

## 先学一点

文件模式 `"w"` 会创建文件或覆盖已有内容。`file.write(text)` 写入字符串。

## 任务与约定

完成 `write_text(path, text)`，将字符串原样写入 UTF-8 文件，覆盖旧内容，返回 None。父目录保证存在。

除题目明确要求外，不修改传入的可变数据，不额外打印内容。只验收约定范围内的输入，不要求猜测未说明的规则。

## 示例

`write_text("result.txt", "完成")` 后文件内容为 `完成`。
