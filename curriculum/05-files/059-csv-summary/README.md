# 059 · 汇总销售表

## 学习目标

从文件记录计算业务结果。

## 前置知识

先完成第 058 题及其前置练习；本题复用此前学过的知识。

## 先学一点

读取 CSV 后可以边遍历边累计，不需要手工拼接或解析数值。

## 任务与约定

完成 `sales_total(path)`，UTF-8 CSV 表头 price,quantity，值均为非负整数。返回所有行的单价乘数量之和，只有表头时为 0。

除题目明确要求外，不修改传入的可变数据，不额外打印内容。只验收约定范围内的输入，不要求猜测未说明的规则。

## 示例

内容 `price,quantity\n100,2\n50,3\n` → `350`
