# 065 · 修复跨调用数据泄漏

## 学习目标

识别可变默认参数的问题。

## 前置知识

先完成第 064 题及其前置练习；本题复用此前学过的知识。

## 先学一点

默认参数在定义函数时创建一次。`items=[]` 会让多次调用共享同一个列表。使用 None 作为默认值，可以每次创建新列表。

## 任务与约定

修复 `add_item(item, items=None)`：item 是字符串；items 为字符串列表或省略。返回追加 item 后的新列表，已有列表也不得被修改。不同调用互不影响。请修改起始代码中的错误签名和逻辑。

除题目明确要求外，不修改传入的可变数据，不额外打印内容。只验收约定范围内的输入，不要求猜测未说明的规则。

## 示例

`add_item("a")` → `["a"]`，随后 `add_item("b")` → `["b"]`。
