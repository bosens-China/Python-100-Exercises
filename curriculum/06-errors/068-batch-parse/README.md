# 068 · 批量导入并报告错误位置

## 学习目标

让单条坏数据不阻塞整批处理。

## 前置知识

先完成第 067 题及其前置练习；本题复用此前学过的知识。

## 先学一点

`enumerate(items, start=1)` 同时给出从 1 开始的序号和内容。可以在每轮循环内部处理转换错误。

## 任务与约定

完成 `parse_counts(lines)`，输入字符串列表。逐条使用 int 转换，保留成功值顺序；失败记录返回其从 1 开始的行号。返回 `{"values": [...], "errors": [...]}`，负数也合法。

除题目明确要求外，不修改传入的可变数据，不额外打印内容。只验收约定范围内的输入，不要求猜测未说明的规则。

## 示例

`parse_counts(["2", "bad", "-1"])` → `{"values": [2, -1], "errors": [2]}`
