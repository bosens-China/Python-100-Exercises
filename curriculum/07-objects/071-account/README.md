# 071 · 管理账户余额

## 学习目标

在改变状态前完成校验。

## 前置知识

先完成第 070 题及其前置练习；本题复用此前学过的知识。

## 先学一点

方法失败时通常不应留下部分状态改变。先检查条件，再更新余额，可以避免扣款失败却改变数据。

## 任务与约定

实现 `Account(balance=0)`，输入和操作金额均为整数分。初始余额不能为负；`deposit(amount)`、`withdraw(amount)` 只接受正金额，取款不能超过余额，违反规则抛 ValueError。成功返回新余额，失败余额不变。balance 为可读属性。

除题目明确要求外，不修改传入的可变数据，不额外打印内容。只验收约定范围内的输入，不要求猜测未说明的规则。

## 示例

`Account(100).withdraw(30)` → `70`
