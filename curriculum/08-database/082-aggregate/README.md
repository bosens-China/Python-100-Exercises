# 082 · 汇总任务完成数量

## 学习目标

使用 SQL 聚合。

## 前置知识

先完成第 081 题及其前置练习；本题复用此前学过的知识。

## 先学一点

`COUNT(*)` 统计行数；`GROUP BY done` 可按完成状态分组。空表或缺少某组时要补充零值。

## 任务与约定

完成 `task_counts(db)`，tasks 的 done 只取 0 或 1。返回 `{"pending": 未完成数, "completed": 完成数}`，两个值均为整数；空表也保留两个键，不修改数据库。

除题目明确要求外，不修改传入的可变数据，不额外打印内容。只验收约定范围内的输入，不要求猜测未说明的规则。

## 示例

两条未完成、一条完成 → `{"pending": 2, "completed": 1}`。
