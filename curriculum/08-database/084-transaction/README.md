# 084 · 保证转账全部成功或全部回滚

## 学习目标

把多次写入放在同一事务。

## 前置知识

先完成第 083 题及其前置练习；本题复用此前学过的知识。

## 先学一点

`with db:` 把其中的写操作作为事务：全部成功才提交，抛出异常会回滚。本题只是事务练习，不包含真实支付或并发账户系统。

## 任务与约定

完成 `transfer(db, source, target, amount)`，整数 ID 和整数分金额。已有 accounts(id, balance) 表，连接无未提交事务。金额必须为正且账户不同，否则 ValueError；任一账户不存在则 KeyError；余额不足则 ValueError。成功扣款、入账并提交，返回 None。任何失败（包括数据库写入异常）都不能留下部分余额修改；数据库异常继续抛出。

除题目明确要求外，不修改传入的可变数据，不额外打印内容。只验收约定范围内的输入，不要求猜测未说明的规则。

## 示例

账户余额 100、20，转账 30 后为 70、50。
