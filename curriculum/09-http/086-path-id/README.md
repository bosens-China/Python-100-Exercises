# 086 · 提取路径中的任务 ID

## 学习目标

把路径结构转换为业务参数。

## 前置知识

先完成第 085 题及其前置练习；本题复用此前学过的知识。

## 先学一点

`text.split("/")` 按斜杠拆分。路径匹配应完整，不要把多余尾段或类似前缀误认为合法。

## 任务与约定

完成 `task_id(path)`。只接受 `/tasks/` 后跟 ASCII 数字，数字表示正整数；允许前导零。不接受尾部斜杠、负号、查询串、零或其他路径。合法返回 int，否则 None。输入保证为字符串。

除题目明确要求外，不修改传入的可变数据，不额外打印内容。只验收约定范围内的输入，不要求猜测未说明的规则。

## 示例

`task_id("/tasks/007")` → `7`；`task_id("/tasks/7/edit")` → `None`。
