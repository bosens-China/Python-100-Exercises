# 087 · 校验创建任务的请求体

## 学习目标

把外部输入转换为明确的业务数据。

## 前置知识

先完成第 086 题及其前置练习；本题复用此前学过的知识。

## 先学一点

外部请求数据不能直接信任。先检查结构和字段类型，再做字符串清理与长度判断。

## 任务与约定

完成 `validate_body(body)`。body 必须为 dict 且 title 为 str，去首尾空白后长度为 1–80。成功只返回 `{"title": 清理后的标题}`，忽略额外字段；其他输入均抛 ValueError。

除题目明确要求外，不修改传入的可变数据，不额外打印内容。只验收约定范围内的输入，不要求猜测未说明的规则。

## 示例

`validate_body({"title": " 学习 ", "done": True})` → `{"title": "学习"}`
