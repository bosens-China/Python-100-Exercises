# 088 · 解析分页查询参数

## 学习目标

为缺省值和非法值设定不同规则。

## 前置知识

先完成第 087 题及其前置练习；本题复用此前学过的知识。

## 先学一点

模拟查询参数用字典表示字符串值，`.get("page", "1")` 仅在键缺失时采用默认值。空字符串不是缺省参数。

## 任务与约定

完成 `parse_page(query)`，query 为字典。缺少 page 时返回 1；存在时必须是非空 ASCII 数字字符串，数值为 1–1000，允许前导零。非法抛 ValueError，忽略其他键。

除题目明确要求外，不修改传入的可变数据，不额外打印内容。只验收约定范围内的输入，不要求猜测未说明的规则。

## 示例

`parse_page({"page": "02"})` → `2`；`parse_page({})` → `1`。
