# 094 · 任务清单：创建与编号

## 学习目标

管理稳定 ID 和新增状态。

## 前置知识

先完成第 093 题及其前置练习；本题复用此前学过的知识。

## 先学一点

Store 用字典按 ID 保存任务，下一 ID 单独递增。输入校验失败时不应消耗 ID，返回值也不应暴露内部记录。

## 任务与约定

保留已提供 domain.py，在 store.py 实现 `Store()` 与 `add(title)`。从 1 开始分配递增 ID，调用 new_task 校验；失败不保存且不消耗 ID。成功返回记录副本。不同实例独立。

除题目明确要求外，不修改传入的可变数据，不额外打印内容。只验收约定范围内的输入，不要求猜测未说明的规则。

## 示例

连续添加 A、B → ID 分别为 1、2。
