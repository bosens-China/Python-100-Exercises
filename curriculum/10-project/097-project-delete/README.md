# 097 · 任务清单：删除且不复用 ID

## 学习目标

区分数据位置与稳定标识。

## 前置知识

先完成第 096 题及其前置练习；本题复用此前学过的知识。

## 先学一点

删除任务后，其 ID 不应该马上指向另一条任务；下一 ID 来自递增计数器，而不是当前记录数量。

## 任务与约定

实现 `Store.delete(identifier)`：ID 类型恰好为 int 且存在时删除并返回 True，其他返回 False。删除不重新编号，后续新增不复用已分配 ID。其余方法保持原契约。

除题目明确要求外，不修改传入的可变数据，不额外打印内容。只验收约定范围内的输入，不要求猜测未说明的规则。

## 示例

添加 ID 1、2，删除 2，再添加任务 → ID 3。
