# Python 100 课程目录

面向零基础与转行学习者。每题依次提供知识铺垫、任务约定、示例与分层提示。

网站正在规划中，此目录是内容源，不是已发布的在线编辑器。

| 大类 | 题号 | 目标 |
|---|---|---|
| [基础语法与数据类型](./01-basics/README.md) | 001–012 | 读懂数值、字符串和布尔值，用表达式返回计算结果。 |
| [条件判断与循环](./02-control-flow/README.md) | 013–024 | 把业务规则写成分支，使用循环处理重复任务。 |
| [常用数据结构](./03-collections/README.md) | 025–038 | 用列表、字典和集合组织、查询和汇总数据。 |
| [函数与代码组织](./04-functions/README.md) | 039–050 | 设计函数契约、复用逻辑，并拆分简单模块。 |
| [文件与数据处理](./05-files/README.md) | 051–060 | 在练习工作区处理文本、JSON 和 CSV。 |
| [异常处理与调试](./06-errors/README.md) | 061–068 | 识别错误边界、阅读失败信息并修复业务缺陷。 |
| [类与对象](./07-objects/README.md) | 069–076 | 封装独立状态，通过组合与基本继承复用行为。 |
| [数据库基础](./08-database/README.md) | 077–084 | 在内存 SQLite 中练习 SQL、约束和事务。 |
| [HTTP 与接口逻辑](./09-http/README.md) | 085–092 | 通过模拟请求响应练习接口业务，不启动真实服务器。 |
| [综合项目：任务清单](./10-project/README.md) | 093–100 | 逐步实现任务清单的数据校验、存储、查询和接口。 |

后续大类复用前面已学知识；每题执行与验收独立。综合项目提供上一步的完整基础代码。

HTTP 题为模拟业务接口，文件使用练习工作区，数据库使用内存 SQLite；不代表生产环境部署训练。

维护题目请阅读[题库作者说明](../docs/authoring.md)。
