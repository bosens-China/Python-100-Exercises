# Python 100 产品决策

## 产品定位

- 当前决策：面向中文零基础和转行学习者，以渐进练习训练初级 Python 开发能力，包括业务实现、数据处理、测试和调试。
- 为什么：学习者需要清晰的知识顺序、可操作的任务及及时反馈，逐步从单点练习过渡到项目。
- 边界 / 非目标：课程通过表示满足已覆盖的要求，不承诺就业或职业资格，也不等同于生产部署经验。
- 权威入口：[项目说明](../README.md)。

## 学习方式与交付边界

- 当前决策：产品以全程在线学习为约束，学习者不需要安装 Python、克隆仓库或使用终端。本仓库已实现题库、维护工具与桌面端在线工作区，并发布至 GitHub Pages。
- 为什么：减少零基础用户开始学习和获得反馈前的环境负担。
- 边界 / 非目标：维护者的本地检查不属于学习者流程；标准 Python 验证不能替代浏览器兼容性验收。
- 权威入口：[题库作者说明](./authoring.md)。

## 课程身份与历史兼容

- 当前决策：现行课程标识为 `python-100-v2`；题号只在同一课程版本内标识内容。旧版归档为 `legacy-v1`。
- 为什么：新课程按能力顺序重新出题，不能将旧版同号题的答案和完成状态自动套用。
- 边界 / 非目标：归档用于追溯，不进入当前题库或默认验证；不维护双套现行课程。
- 权威入口：[旧版归档说明](../legacy/README.md)。
