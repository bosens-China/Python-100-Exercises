# 题库作者说明

## 目录与唯一来源

课程标识为 `python-100-v2`。大类与顺序由 [course.json](../curriculum/course.json)维护；每题有稳定的三位编号，路径为 `curriculum/<category>/<id>-<slug>/`。

每个题目目录包含：

| 文件 | 职责 |
|---|---|
| `exercise.json` | 编号、分类、标题、学习目标、前置题、路径和可编辑文件清单 |
| `README.md` | 知识铺垫、任务契约、示例与分层提示 |
| `starter/*.py` | 学习者打开题目时看到的代码；综合题可含已完成的前置模块 |
| `solution/*.py` | 一份可通过测试的参考实现，与起始代码文件集合相同 |
| `test/test_solution.py` | 具名的行为测试，每个 `test_` 函数是一项反馈 |

网站读取这些内容导出的数据，不复制维护第二套题目。分类目录中的 Markdown 表格用于 GitHub 浏览；调整编号、标题或学习目标时同步表格。

目前文件清单只支持同一工作区内的顶层 Python 模块，入口默认为 `main.py`。新增题型需要扩展这个契约时，同步导出与执行测试，不能只增加 UI。

## 出题要求

- 普通题聚焦一个主要新知识点，综合题只组合已学内容。
- 先解释必要概念和语法，再要求独立使用；基础题提供函数外壳。
- 明确参数类型、返回结构、空输入、边界、异常类型与是否修改传入数据。测试不要求题目未说明的行为。
- 参考实现只是一个例子，不要求源码一致或特定行数；知识教学可以推荐某种写法，行为测试不强行检查实现细节。
- 使用固定数据、工作区文件、内存数据库和模拟依赖。不要访问公网、读取个人文件、使用账号或系统环境中的业务数据。
- 对影响数据完整性的题，检查失败前后状态；导入不能部分覆盖，事务不能部分提交。
- 测试不能只检查文件存在或文档字数。文件题应检查内容，数据库题检查记录，接口题检查响应及状态变化。
- 各题与各测试互相独立；综合题附带该步需要的基础模块，保留前面功能的回归用例。

## 测试契约

题目测试使用普通 Python 函数和 assert，无第三方测试依赖：

```python
def test_normal():
    assert student.total(120, 30) == 150

def test_invalid():
    with raises(ValueError):
        student.validate_age(-1)
```

这里两个函数仅示意不同题的写法，实际题目只调用自己的公开函数。`student` 是本次加载的 `main.py` 模块；`raises` 验证异常类型。测试不能导入参考答案。

[判题内核](../tools/grader.py)接收文件名到源码的映射及测试源码，返回 JSON 兼容的 `passed`、`total`、`passed_count` 和逐项 `cases`。每项含状态、错误信息、调用栈、标准输出和错误输出。常见的相等/身份断言会补充预期与实际值。

每项测试重新加载整份代码和独立的临时文件工作区，并清理该工作区的导入模块。测试可自行建立数据文件和 SQLite 连接。相同测试内的多次调用用于验证连续操作；不同测试不共享学生状态。学生代码加载失败记为未通过，测试初始化错误标为内容错误，空测试不能通过。

这是可重复的学习反馈机制，不是恶意代码安全沙箱。它会改变当前目录及 Python 导入状态，不支持同进程多线程并行判题。浏览器宿主负责独立执行单元、停止、超时、输出和资源限额；本地维护命令只运行仓库内已审查的代码。

## 维护检查

在仓库根目录使用 Python 3.12 运行：

```bash
python -m tools.course validate
python -m tools.course check
python -m pytest -q
```

- `validate` 检查目录、编号、依赖顺序、必需内容、文件清单和 Python 语法。
- `check` 检查所有参考答案通过，以及所有未完成起始代码不能整题通过。每份实现运行于独立子进程，超过 15 秒即失败。
- `pytest` 检查工具行为，以及能通过部分示例的错误解法是否被拒绝。

查看某题的结构化结果：

```bash
python -m tools.course grade 053 --kind solution
python -m tools.course grade 053 --kind starter
```

`grade` 返回判题结果时进程退出码为 0，即使学生未通过；调用方读取 JSON 中的 `passed`。无效题号或工具调用失败退出非零。直接调用 `grade` 不带执行超时，自动批量质量检查使用 `check`。

## 导出与浏览器验收

```bash
python -m tools.course export dist/course.json
```

导出包含课程和分类、每题元数据、Markdown 题目、起始文件和行为测试，`schema_version` 为 1。参考答案不在导出中，但后期题的起始工作区会包含必要的前置实现。浏览器可将编辑后的 files 和对应 tests 交给同一 Python 内核。

当前题库已在标准 Python 与真实浏览器 Pyodide Worker 中验证，100 道参考实现通过 329 项检查，100 份起始代码均未误判通过。题目变更后仍须重新执行浏览器验收，包括 SQLite、文件与多模块加载；前端命令见[前端说明](../web/README.md)。导出或本地验证不表示已经发布网站。
