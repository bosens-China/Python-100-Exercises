# 面向初学者的代码错误反馈

- 基线：[在线学习工作区](../../prd/online-practice.md)。
- 依赖：当前在线编辑器与浏览器 Python 执行环境。

## 背景与目标

帮助零基础学习者更早发现漏冒号、括号未闭合与缩进错误，减少反复提交和寻找报错位置的负担。

## 新增与范围

- 输入停顿后检查语法，在对应代码位置标出错误；编辑时取消过期检查，反馈必须对应当前文件版本。
- 运行结果中的学生代码错误位置可以点击，切换到对应文件并定位行；不把判题内核或测试文件当成可编辑文件。
- 为常见语法和缩进错误补充简短中文解释，同时保留原始 Python 报错。
- 延续桌面端、静态托管与浏览器执行；本轮不引入完整语言服务器、跨文件类型分析或后端。

## 验收标准

- 漏冒号、未闭合括号、缩进错误能定位；修复后提示消失。
- 快速编辑或切换文件不显示过期错误，不阻塞编辑器和正在运行的提交。
- 多文件题的错误位置链接能打开正确文件和行。
- 正常代码不产生语法错误提示；首次加载和执行环境异常仍有明确反馈。

## 后续影响

基础补全保持现状，完整类型检查和跨文件智能提示待真实学习反馈证明需求后再评估。
