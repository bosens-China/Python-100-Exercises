# 课程内容与验收

## 课程组织

- 当前决策：课程包含 100 道题，按基础语法、条件与循环、数据结构、函数与代码组织、文件与数据处理、异常与调试、类与对象、数据库、HTTP 与接口逻辑、综合项目共 10 个大类组织。
- 为什么：从表达式、业务规则和数据组织逐步进入模块、状态与项目，避免突然跨越必要前置知识。
- 边界 / 非目标：不以复杂算法、元类、生产部署或第三方账号作为入门门槛。
- 权威入口：[课程目录](../../curriculum/README.md)、[课程清单](../../curriculum/course.json)。

## 题目体验

- 当前决策：每题提供学习目标、前置知识、知识铺垫、任务与边界、示例、起始代码及两层提示。早期提供函数外壳，普通题聚焦主要新知识点，综合题复用已学知识。
- 为什么：零基础学习者需要理解要做什么、为什么这样做，以及如何从反馈中继续。
- 边界 / 非目标：题目之间存在知识依赖，但不共享可变执行状态；综合项目的每步提供完整的前置模块，支持独立开始和验收。
- 权威入口：[题库作者说明](../authoring.md)。

## 自动验收

- 当前决策：测试验证输入输出、适用边界、异常和状态变化；参考实现用于证明题目可解，未完成代码不得整题通过。单次测试拥有独立工作区，失败反馈包含具体错误及适用的预期、实际值。
- 为什么：让学习者根据行为反馈修正实现，避免用文件存在或字数冒充能力验收。
- 边界 / 非目标：不要求源码与参考答案一致；参考答案与测试可公开，不承诺防作弊、隐藏测试或可信成绩认证。测试覆盖也不等于数学意义上的完全正确。
- 权威入口：[判题内核](../../tools/grader.py)、[维护入口](../../tools/course.py)。

## 运行依赖与数据

- 当前决策：题目运行只使用 Python 标准库；文件位于练习工作区，数据库使用内存 SQLite，HTTP 题使用模拟请求响应和依赖函数。综合项目完成任务的创建、查询、完成、删除、导入导出与保存恢复。
- 为什么：题目行为可重复，减少外部服务、网络和个人环境造成的干扰。
- 边界 / 非目标：模拟接口不代表真实服务器；工作区文件不是跨设备进度存储。浏览器运行与资源限制由网站执行宿主验收，判题内核不承担恶意代码安全隔离。
- 权威入口：[题库作者说明](../authoring.md)。

## 内容来源

- 当前决策：题目元数据、说明、起始文件和测试在课程目录中维护，通过统一出口生成网站数据，默认不导出当前题参考答案。维护工具沿用 pytest 进行回归检查。
- 为什么：修改题目后，仓库与网站能复用同一份内容契约。
- 边界 / 非目标：内容导出不等于网站发布；后期起始文件包含已完成的前置代码，这是项目递进练习的一部分。
- 权威入口：[题库作者说明](../authoring.md)、[内容导出实现](../../tools/course.py)。
