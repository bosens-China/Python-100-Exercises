# 在线学习工作区

- 当前决策：桌面优先，按章节与题号浏览，在线阅读知识、约定与分层提示。使用 Vite + React + TypeScript，启用 React Compiler，组件以 Ant Design 为主，UnoCSS 仅辅助布局；主题默认跟随系统，可切换深浅色。
- 为什么：让零基础用户打开网页即可开始练习，并保持后续多文件项目的学习连续性。
- 交互：CodeMirror 多文件编辑；运行示例检查首个行为测试且不记通关，提交检查运行全部测试。结果逐项展示，代码修改后标明结果来自旧版本。
- 执行：GitHub Pages 静态资源 + Pyodide Worker，复用 Python 判题内核，无判题后端。文件、内存 SQLite、模拟接口与多文件题已完成浏览器兼容性验证。
- 恢复：环境加载有失败和重试入口，初始化上限 90 秒，执行上限 10 秒，支持主动停止，每项输出分别限 32,000 字符。
- 保存：localStorage 按课程版本保存源码和通过状态，提供导出与确认导入、确认重置。编辑已通过代码后视为当前未验证；非法导入不覆盖有效数据。
- 边界：首版仅验收桌面 Chrome；不提供移动端适配、账号、跨设备自动同步、隐藏测试或防作弊承诺。不要在执行工作区放置凭证。
- 发布状态：代码与静态部署配置已实现；真实 GitHub Pages 发布及发布后的最终验收仍待完成。
- 权威入口：[前端维护说明](../../web/README.md)。
