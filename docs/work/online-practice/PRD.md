# 在线 Python 练习网站

- 基线：[现行产品决策](../../PRD.md)与[课程内容与验收](../../prd/curriculum.md)。
- 依赖：已交付的题库内容、导出契约和判题内核，接入说明见[题库作者说明](../../authoring.md)。

## 背景与目标

让零基础或转行用户打开网页就能学 Python，全程在线读题、编写代码、运行示例、提交测试并查看反馈，无本地安装步骤。

## 新增、变更与移除

- 按大类、题目顺序浏览，展示前置知识、题目、分层提示和完成状态。
- 在线编辑器加载起始文件，支持后期题目的多文件工作区。
- 区分运行示例与提交检查，展示输出、错误位置和逐项测试反馈。
- 自动保存草稿及学习进度；支持重置当前题，重置前告知会清除的内容。
- 使用当前浏览器保存进度，提供导出和导入。清理浏览器数据会丢失未导出的记录；不宣称跨设备自动同步。
- 初期优先 GitHub Pages 静态托管和浏览器 Python 执行；执行方案必须通过全部题型的兼容性验证。
- 不因某题无法运行而把学习者引导到本地。必要的执行能力调整保持在线体验，并在实施前重新评估托管边界。

## 范围与非目标

- 全部 100 题均能在线完成并自动验收，沿用题库唯一内容源。
- 运行环境加载有明确状态、失败原因和重试入口；不能无限等待。
- 执行可停止、有超时反馈，死循环不能使编辑器失去响应；每次提交重置测试环境。
- 不把浏览器执行单元当成对恶意代码的安全隔离承诺；公开自学代码与测试，不在执行环境放置凭证。
- 不包含账号、云端进度同步、排行榜、AI 判题或生产服务部署。
- 首版只支持桌面端，以课程目录、题目说明和代码工作区为核心。
- 使用 Vite + React + TypeScript，启用 React Compiler，主要组件使用 Ant Design，少量 UnoCSS 辅助布局。

## 验收标准

- 从 GitHub Pages 实际部署路径打开课程、直接打开题目链接和刷新均可使用。
- 新用户无需终端和本地安装，可从第 1 题完成到第 100 题。
- 100 题参考实现通过浏览器内测试，起始代码不能误判通过；文件、数据库、多文件和异常题均覆盖。
- 错误实现显示测试反馈；语法错误、运行异常、超时、停止和运行环境加载失败均可恢复。
- 切题、刷新后恢复该课程版本的代码和进度；导入非法记录不得覆盖有效数据。
- 测试失败不记为完成；编辑已通过的代码后区分上次通过与当前未验证状态。
- 无服务器判题或外部账号时，浏览器仍可完成全部核心学习流程；不依赖公网业务接口。
- 1024×768 的桌面视口无需页面横向滚动，题目、编辑器与判题操作保持可用。

## 文档与兼容性影响

桌面端实现、题库浏览器兼容性和 [GitHub Pages](https://bosens-china.github.io/Python-100-Exercises/) 首次发布验收已完成，现行行为已归入[在线学习工作区](../../prd/online-practice.md)。本实施目录继续跟踪小屏优化的线上发布与 `main` 分支保护。账号同步与可信考核不属于当前已确认范围，不预建后端。
