- 文件内容除历史 README 的图片链接外保留原样；部分旧题尚无实现、测试依赖共享项目或只检查文件存在，不作为新课程质量基准。
- 旧依赖位于 [requirements.txt](./requirements.txt)。如维护者需要复现旧行为，应在独立环境中以本目录为工作目录运行对应测试。
